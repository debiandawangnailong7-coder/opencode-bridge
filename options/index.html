Extension ID

—

Use this ID with new OpenCodeBridge({ extensionId }) in your web app. In Safari this value is the extension's bundle identifier, not a Chrome-style hash. For unpacked Chrome builds, keep the extension installed at a stable path or add a key to manifest.json.

Connection transports

—

  • Direct — web pages connect through externally_connectable. Chrome's primary path.
  • Content-script relay — the SDK posts messages to a content script, which forwards them over a privileged port. Safari uses this path; Chrome falls back to it automatically.

Safari requires per-website access: Safari Settings → Extensions → OpenCode Bridge → Website Access, then allow the site that runs the SDK (for local development, allow localhost or choose "Always Allow on Every Website"). Reload the page after changing access.

For development builds, enable Safari → Settings → Advanced → Show features for web developers, then Develop → Allow Unsigned Extensions. Safari 16.4+ is recommended (full MV3 service worker support); older versions may need the converter's background-page fallback.
